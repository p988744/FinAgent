## Archive Policy

**When to Archive:**
- Documentation superseded by consolidated sources
- Meta-documentation (summaries of summaries)
- Historical session notes no longer needed for reference
- Implementation notes integrated into checkpoint docs

**When to Keep:**
- V1_0_RELEASE_PLAN.md (master plan)
- Checkpoint completion reports
- Technical references (CLAUDE.md, README.md)
- API guides (METADATA_QUICK_REFERENCE.md)
